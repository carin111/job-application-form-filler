# Core rules

- Use only verified facts from the generated context or facts supplied in the current conversation.
- Never invent dates, metrics, titles, awards, certificates, contacts, tools, responsibilities, official translations, or salary.
- Preserve the user's strongest detailed wording; shorten only for field limits or an explicit request.
- Put internships in **实习经历 / Internship Experience**, not **工作经历 / Employment**, unless no internship section exists.
- Select actual date options and verify rendered values after rerender or save.
- Do not enter placeholders, `UNKNOWN`, or internal notes into live forms.
- Do not overwrite richer user-entered content with a generic summary.
- Treat editing, draft saving, attachment upload, consent, messaging, and final submission as separate actions.
- Stop after the authorized action and report filled, skipped, saved, uploaded, and submitted status.

- When the private index provides `role_priority`, respect it before generic tag scoring.
